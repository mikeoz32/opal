    module LF::UI

    Overview

    Optional stateless HTML primitives for normal server rendering and LiveView.

    Load with require "opal/ui". Components return structural LF::LiveView::Rendered values and use the precompiled Tailwind theme made available by LF::UI.stylesheet_tag or LF::UI.mount_assets.
